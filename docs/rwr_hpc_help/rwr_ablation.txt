Distributed layer ablation using RWR embeddings on multiplex networks
Usage: /lustre/orion/syb111/proj-shared/Personal/krusepi/projects/llms/mentor-rl/external/rwr_hpc/build_frontier/apps/rwr_ablation/rwr_ablation [OPTIONS]

Options:
  -h,--help                   Print this help message and exit
  -f,--flist TEXT REQUIRED    Path to the file containing paths to and names of each layer in the multiplex
  --no_edgelist_headers       Indicates that the edge lists contains no headers
  -s,--seed_file TEXT         Tab delimited file containing seeds to initalize RWR probabilty vectors with.
                              Seeds on a single line will be combined in a single vector.
                              Seeds on mulitple lines will be encoded in seperate vectors.
                              Any empty value will treat each node in the multiplex as a seed separately.
  --no_set_ids                Indicates that the pertubation_file and seed_file contains no set ids
                              .These ids are stored as the first value in each row.
  -o,--output_dir TEXT [./]   Output directory
  -r,--restart FLOAT:FLOAT in [0 - 1] [0.7] 
                              Probabilty of restart during random walk
  -d,--delta FLOAT:FLOAT in [0 - 1] [0.5] 
                              Probabilty of jumping from a layer to any other layer in the mulitplex
  --reduction_method TEXT:{geometric,arithmetic,sum,none} [geometric] 
                              The method used to reduce RWR embeddings to a single value per node
  --threshold FLOAT [1e-10]   Used to determine when RWR converges
  --distance_metric TEXT:{spearman,pearson,cos} [spearman] 
                              Metric used to calculate distance between all pairs of RWR encodings
